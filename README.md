# 🧠 Featured Projects

## 🌦️ IoT Weather Monitoring & ML Forecasting

An end-to-end environmental monitoring and forecasting system combining **IoT, cloud data collection, time-series feature engineering, and machine learning**.

**Key work:**

* Arduino UNO R4 WiFi + DHT22 for temperature and humidity collection
* Real-time data transmission using HTTP
* ThingSpeak cloud dashboard for historical visualization
* Offline buffering to prevent data loss during network interruptions
* Time-based, lag, and rolling-average feature engineering
* Regression and LSTM models for temperature/humidity forecasting
* RMSE, MAE and R² based model evaluation
* Flask/FastAPI API for prediction serving

**Tech:** `Python` `Pandas` `Scikit-learn` `TensorFlow/PyTorch` `LSTM` `Arduino` `ThingSpeak` `FastAPI`
